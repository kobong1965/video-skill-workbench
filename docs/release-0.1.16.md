## 更新内容

从上一公开版 0.1.6 起，包含单人直用、多接口自动分配与并行任务、圆角渐变界面、大脚本预览、统一提示词面板、款号图套与多款号选择、任务／记录双缩略图和中文状态、LibTV 导入修复和脚本分组。
