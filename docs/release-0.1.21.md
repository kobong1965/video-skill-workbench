# 视频 Skill 工作台 0.1.21

保留 0.1.20 的“设置 → 软件更新 → 检查更新”板块，修复 Windows 完整程序包中合法运行依赖目录被隐私过滤规则误删的问题。此前受影响的包可能在启动时提示缺少 undici 的 lib/web/cookies 模块，导致后台未就绪。本版恢复合法依赖实现文件，并增加打包回归和程序包导入检查。

发布范围仍只包括软件程序，不同步使用者的 Skill、素材、商品资料、账号、密钥和数据库。设置页显示实际桌面主程序版本；更新窗口检查 GitHub 最新稳定版并校验程序 ZIP 的 SHA-256。

已有本机免登录定制可通过固定数据目录内的本机偏好迁移，仅对原有启用的本机单人模式生效；该偏好不随程序分发，默认安装和多人模式继续使用原会话验证。没有既有有效管理员时仍需正常登录。

安装需完成当前任务、保存输入，再将完整软件包解压到 E:\Codex工作盘\ 下独立目录。确认旧后台退出后启动新版，并将快捷方式指向新目录。固定数据目录 E:\Codex工作盘\projects\video-skill-workbench-data 继续沿用；不要同时运行新旧后台。既有安装和历史发行版保留。
