视频 Skill 工作台 · Windows 版 0.1.16

0.1.16 为依赖安全补丁：更新图像处理、接口框架及关联依赖，保留现有创作、图套、多接口、脚本封面和画布状态功能。

创作页顶部提供“保存草稿”和“下一步”；上传商品图后还需选择至少一个脚本，才能进入设置。
素材页可上传并保存款号图套；下次在创作页“选款号”即可复用图片，选脚本后仍经“下一步”设置弹窗提交。
选款号支持多选、取消和排序，每任务最多 6 个图套、36 张唯一图片；每个保存图套仍最多 12 张。
多款号提供“换色／搭配／对比”；对比时第一组为主商品，图片保留各自款号归属。选择款号不会自动生成。
任务栏只在创作页显示；脚本、记录、素材及结果页使用完整内容宽度。
Skill 卡片去掉类别、版本与可见性标签，预览扩大；任务卡显示商品主图、所用脚本封面、中文状态和查看详情。
生成记录也显示商品主图与脚本封面。组合脚本按顺序全部保留，可横向查看；悬停封面显示脚本名，点击进入对应任务。
任务状态直接显示“正在生成”“已完成”；排队、连接中断、生成失败和结果需修正各自显示，不假报完成。
全部提示词合并为一个编辑面板，可复制、修改和保存新版本。不再要求确认满意度。
结果页移除“参考图准备”和“复制与导出”板块，原素材及历史记录保留；仍可从顶部导入画布。

修复 LibTV 回读去除末尾换行时误报“画布视频提示词已修改”的问题。
可在原导入记录点击“继续导入”，复用已有素材和节点，不重复建画布，也不自动生成。
提示词正文实际改动和已有生成任务／结果的保护保持不变。

当前为单人使用模式：配置接口地址、模型和 API Key 后可直接生成，不设软件内额度或重试次数上限，也不需要费用确认。
管理设置支持多个文字／视觉接口及多个图片接口，每组可分别填写名称、地址、模型、密钥、启用状态和并发上限。
新计划由系统自动分配到已启用、能力匹配且有空位的接口，无需为每个计划手工选择。
默认全局同时处理 8 项、每接口同时处理 4 项，两项均可设置为 1–32；所有可用空位用满后其余任务等待空位。
任务栏显示正在生成、排队数量和实际接口名称／模型。请求发送后不会因其他接口空闲而自动重发；异常结果须核对后手动重试。
旧单接口配置和密钥自动保留。编辑时密钥框留空表示保留该接口原有密钥；新增接口应填写自己的实际密钥。
会自动使用已启用的 Windows 系统代理或代理环境变量；无需修改 Windows 网络设置。
超时时间填写 0 表示不主动限制响应等待时间；仍会报告实际的连接失败、接口错误或返回格式错误。
已有失败记录可以直接点击“重试这一步”，原任务的商品图、Skill 和历史记录继续保留。

本版优化 1080p/2K 和 Windows 100%/125%/150% 显示缩放：
正文 16px、辅助说明最低 14px、页面标题 28px、区域标题 20px；主要按钮和输入框 48px 高。
窗口缩小时自动调整列数与导航，表格可在自身区域横向滚动。长内容和弹窗可纵向滚动。
窗口增加可见边缘、标题栏分隔线与系统阴影，原拖动、缩放、最大化等操作保持不变。
在 Windows“设置 → 系统 → 屏幕”中调整缩放比例；不建议使用自定义低分辨率或兼容性 DPI 位图缩放。

本版统一使用蜗牛 Logo：软件界面、窗口图标和桌面快捷方式均沿用同一标志。
本机桌面“视频Skill工作台”快捷方式直接打开现有安装，不需要先打开浏览器。

1. 保留整个软件文件夹，双击“视频Skill工作台.exe”。不能只复制一个 exe。
2. 首次使用：点击右上角“⋯”→“首次安装码”，自行设置管理员账号和密码。已有账号无需重新设置。
3. 在脚本库导入已经验证的 ZIP/Markdown 脚本。
4. 在管理设置添加实际文字/视觉接口、模型和密钥并保存，按服务商允许的并发设置上限；单人模式可直接生成。
5. 上传商品、选择 Skill → 下一步 → 常规／高级设置 → 生成提示词。任务加入右侧任务栏，可以继续新建其他商品任务。

创作页显示全部 Skill，可纵向滚动；点击素材播放预览，点击名称／勾选区选择脚本。
任务卡显示商品与脚本双缩略图、中文状态和查看详情；悬停封面可读名称，详细错误在任务详情中保留。服务商未提供进度时不估算百分比。
生成结果中的“导入画布”支持新建 LibTV 画布或选择已有画布。
只上传商品图、已确认参考图、Skill 明确要求的原始对标和提示词，并建立视频节点与连线，不调用模型生成。
导入完成后自行在画布确认模型、时长、比例和声音，再手动生成。LibTV 可能自动填入默认模型／时长，请务必核对。
本包随附 LibTV 官方 CLI 程序，不含账号凭据；画布导入使用本机已登录的 LibTV CLI 会话。

使用“深灰阔腿裤｜对标视频确认版”时，会弹窗提醒同步上传原始完整对标视频。
可直接在弹窗下载原对标；到 LibTV 等外部平台生成时，商品图与对标视频必须连接到同一节点。
工作流截图、单张首帧或已确认成片都不能替代原对标。确认提醒不代表已自动上传或完成连线。
此要求仅作用于包内 workbench.json 明确声明 referenceVideoRequired=true 的 Skill；原普通 Skill 不受影响。

创作页脚本卡片右侧可直接预览包内素材：
- “播放效果”：点击打开视频播放器，可暂停、调整进度、音量和全屏；关闭预览会停止播放。
- “查看图片”：当前版本只有图片时，点击放大包内参考图片，不代表已有视频。
- “暂无预览”：可进入脚本库，查看脚本后补传效果视频或封面。
预览不改变脚本勾选，也不会调用 AI 或消耗生成额度。支持键盘 Tab/Enter 操作，Esc 关闭预览。
素材来源是当前卡片对应的 Skill 版本，优先采用补传的预览视频，保留原始素材不修改。

无边框窗口：拖动顶部空白区域移动窗口，双击顶部最大化／还原。
右上角依次为更多操作、最小化、最大化／还原、关闭；窗口边缘和角落仍可拖动调整大小。
原来的“打开导出文件夹”“打开数据文件夹”“首次安装码”“刷新”“使用说明”均在“⋯”菜单内。

全部上传入口支持直接拖入文件，也保留点击选择：
- 商品主图与补充图：可批量拖入 PNG／JPG／WEBP，单张不超过 20 MB，每任务合计最多 36 张。
- 脚本导入：拖入一个 ZIP（150 MB 内）或 MD（2 MB 内）。
- 脚本效果预览：拖入一个 MP4（150 MB 内）或图片（20 MB 内）。
- 参考图库、固定资产上传和真实尾帧：拖入一张图片（20 MB 内）。
拖入区域会高亮；格式、数量和大小不符合要求时会给出提示。暂不支持直接拖入文件夹。
上传处理期间不接受重复拖入；批量上传部分失败时，已成功的图片会保留，可只重试失败文件。
参考图库、固定资产和真实尾帧仍需按页面要求点击保存／确认，拖入文件不会自动调用 AI。

本机数据固定保存在 E:\Codex工作盘\projects\video-skill-workbench-data。
本包不含你的账号、密码、商品图片、任务和 API 密钥。
旧数据不会被安装包覆盖。更新时只更新软件，不删除数据文件夹。
关闭窗口后，本机后台任务可以继续；重新打开可查看进度。关机期间不会继续生成。
右上角“⋯”中的“打开导出文件夹”可以找到下载的提示词/图片资料包。

此版本需 Windows 10/11 x64、可用 E 盘和已有 Microsoft WebView2。
桌面运行环境为 C# 14 / .NET 10.0.12 LTS，随软件自包含提供，无需安装系统级 .NET；后台使用 Node 24.21.0 LTS。
本机已经检查到 WebView2；其他电脑若缺少，不会静默安装，请联系维护者。
这不是离线 AI，也不是多人远程共享版。实际生成仍需网络、服务商 API 和额度。
自动化测试不等于模型效果保证；真实图片与视频生成效果仍取决于配置的服务商和所选模型。
程序未购买代码签名证书。若系统提示安全检查，不要关闭系统防护，请交由维护者核验文件校验值。

打不开时：等待一会后“重试打开”，或查看“打开数据文件夹”中的 logs。
不要通过删除数据库或资料目录来修复启动问题。
