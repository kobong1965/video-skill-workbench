# 视频 Skill 工作台

Windows 本机视频脚本与素材工作台。保存、预览、版本管理和组合已验证的 Skill，根据商品图片生成中文视频提示词，再到 LibTV 等外部平台生成视频。

当前公开版本：**0.1.6**。本仓库同时包含应用源码、4 套当前 Skill、1 个历史版本及 22 个已保存素材文件。视频和图片是实际文件，不只是外部链接。

## 下载与运行

- **[下载 Windows 软件＋全部 Skill 和素材整合包](https://github.com/kobong1965/video-skill-workbench/releases/download/v0.1.6/VideoSkillWorkbench-0.1.6-Windows-Skills.zip)**
- [只下载 Skill 与素材包](https://github.com/kobong1965/video-skill-workbench/releases/download/v0.1.6/VideoSkillWorkbench-0.1.6-Skills-Materials.zip)
- [版本下载页与校验文件](https://github.com/kobong1965/video-skill-workbench/releases/tag/v0.1.6)

**运行要求：Windows 10/11 x64、可用 E 盘、Microsoft WebView2 Runtime。** .NET 与 Node 运行时已随整合包提供，不需要安装开发工具。当前版本不是任意盘符便携版：软件和运行数据使用 `E:\Codex工作盘`。

1. 完整解压整合包到 `E:\Codex工作盘\artifacts\latest`，保留所有子文件夹。
2. 打开 `VideoSkillWorkbench-0.1.6-AllInOne\Windows\视频Skill工作台.exe`。不要只复制 EXE，不要在压缩包内直接运行。
3. 新电脑首次使用：右上角 `⋯ → 首次安装码`，自行创建管理员账号。已有账号直接登录。
4. 打开“脚本库 → 导入脚本”，逐一导入 `SkillsAndMaterials\import-packages\current` 中的 4 个 ZIP，按下表检查类型和时长。资料以可导入包提供，不会自动写入新电脑的数据库。
5. 在管理设置中配置自己的文字／视觉服务、模型、API 密钥和账号额度；图片接口按需配置。然后上传商品、选择 Skill、生成提示词。

已有安装的用户可继续使用原来的桌面快捷方式；本次公开发布没有修改或清空原安装的数据。不要删除 `E:\Codex工作盘\projects\video-skill-workbench-data`，也不要为了更新把此目录替换为其他人的数据。

## 文件说明

- `apps/`、`packages/`、`database/`：前端、服务、任务与数据库结构源码。
- `desktop/`：Windows 原生宿主和窗口代码。
- `scripts/`、`tests/`：运行、构建、测试和安全导出工具。
- `skills/current/`：4 套当前 Skill 展开文件，包括包内对标、成片、商品与工作流资源。
- `skills/history/`：1 个历史版本。
- `materials/`：工作台保存的全部 22 个原始素材文件。不同保存记录即使内容相同也分别保留，不擅自去重。
- `catalog.json`：版本、类型、时长、文件数量及 SHA-256 清单；不包含账号和数据库记录标识。

可直接在仓库浏览源码与素材；需要运行软件请使用 Releases 的整合包，GitHub 自动生成的 Source code ZIP 不是可执行软件包。导入 ZIP 位于下载的素材包内；源码仓库保留的是 Skill 的展开文件。

## 0.1.6 界面与运行环境

- 正文 16px，辅助说明至少 14px，页面标题 28px，区域标题 20px；主要输入框和按钮 48px 高。
- 弹性布局、响应式列数、可滚动弹窗和表格，适配 1080p／2K 及缩放后的有效窗口宽度。
- Windows Per-Monitor V2 DPI 支持，保留拖动、调整大小、最大化操作，增加窗口边缘与阴影。
- 源码锁定版本：TypeScript 7.0.2、React 19.2.8；Windows 宿主 C# 14／.NET 10.0.12，后台 Node 24.21.0。

发布核验包括软件清单校验、Skill 导出重新解析与引用检查、素材 SHA-256 比对、源码类型检查及 103 项自动化测试。两个下载包分别逐项核验 4,760 与 75 个文件，均与导出副本字节一致。发布准备不会调用付费 AI。真实模型输出取决于用户自行配置的服务，并不由测试通过保证。见 [发布核验记录](docs/release-0.1.6.md)。

## 数据、安全与许可边界

公开包**不包含**原用户数据库、账号密码、登录会话、API 密钥、本机安装码或私人配置。新安装使用自己的账号和设置。软件仅在本机提供服务，不是多人远程部署版本，也不是离线 AI 视频模型。

软件尚未购买代码签名证书，Windows 可能显示安全提示；请核验 Releases 的 SHA-256，不要关闭系统防护。
