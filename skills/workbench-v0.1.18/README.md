# 视频 Skill 工作台 0.1.18 脚本库

这里有 30 个当前脚本和 1 个历史版本。脚本来自工作台的已保存版本，包含分镜、提示词、适配规则与对应的文本资料。公开版对本机路径、示例商品标识和私人链接做了处理。

下载发行页的 **VideoSkillWorkbench-0.1.18-Script-Skills.zip** 并解压。在软件打开 **脚本 → 导入**，从 current 文件夹选择其中一个 ZIP。外层总包用于解压分发。按 catalog.json 或每包内 release-metadata.json 核对脚本名称、类型、时长和标签。

通常只需导入 current。若希望恢复同一脚本的历史版本顺序，先把 history 中该脚本的较早版本导入，再从脚本详情上传 current 对应文件作为新版本。工作台会按导入顺序编号。

公开发行包不随包分发原对标、预览、产品图和聊天截图。需要预览时可以在工作台给已导入脚本补传本人有权使用的视频或封面。标记必需对标的脚本须按随包说明补齐完整对标视频，才能通过工作台自动导入 LibTV。

目录与每包 SHA-256 见 catalog.json。每个单独的 ZIP 已通过本版工作台实际使用的导入解析器。
