# 镜前裤装换款规则

## 商品证据

这套方案用于裤装换款。正常输入一张或多张清楚产品图即可，图数不必是三；正面清楚而没有背图时仍可直接完成，因为固定表演不转背。若图片混有不同SKU且无法确定目标，询问目标款；若完全没有图片，要求提供产品图。上衣/裙装等无法直接套用裤腿和前腰动作的商品，只确认是否要改品类，不默默改整套脚本。

图片仅定义本次商品：颜色与明暗分区、水洗/印花、轮廓、裤长、腰头、口袋、可见缝线与下摆。不继承图中脸部、身体比例、裸上身、纹身、上衣、鞋、站姿、背景、棚光或文字标语。人物、搭配和房间由模板固定。

只描述看清或本次明确提供的事实。未显示的背面不补旧款五边形袋或装饰车线；不靠“牛仔裤”常识认定内部拉链；不由静态拉布图认定弹力。成分、加绒、厚薄、透气、防水、保暖、塑形等性能及品牌、价格、折扣、销量必须有本次证据才可使用。未知的非必要信息直接省略，不为它们反复追问。对被遮挡部分使用“按该视角真实可见部分呈现”，不要求新增背面镜头。

## 替换位

模板中的双花括号是内部编辑标记。全部用当前商品的具体、可执行中文或英文填充后再输出，不能把括号或表格交给视频模型。

| 替换位 | 填写内容及限度 |
|---|---|
| UNDERWEAR_EDGE_VISIBILITY | 默认逐字填“只露一小条纯白无字内裤腰边。”；仅当新款腰位自然遮挡时改成保留纯白无字内裤且不强行露边，不拉低商品腰位。人物其他服装、身份与配饰不改。 |
| UNDERWEAR_EDGE_RESPONSE | 默认逐字填“露出的纯白无字内裤边只随接触轻微整理，不作拉伸表演。”；新款遮挡边缘时改成只轻整实际可见裤腰，不把内裤边从裤腰中拉出来。手路径和时间不变。 |
| PRODUCT_SUBTITLE_CLEARANCE | 仅填本次真实可见的结构/细节名称，承接“以小号字降低对…的遮挡”；如无细节证据写“商品轮廓与关键区域”。只换宾语，不改字号、字位或字幕持续方式。 |
| PRODUCT_IMAGE_ROLES | 按本次实际上传顺序，逐张说明图号/可识别文件名、视角及商品用途。仅引用实际有的图片；不引用包内原视频或归档旧图。 |
| PRODUCT_IDENTITY_AND_CONSISTENCY | 完整当前商品段落，含可见颜色/结构/轮廓/细节和对应一致性要求；不从原稿拼接颜色、窄裤管、脚踝堆叠、袋型或禁用色。全片正面、不新增转身这一约束保留。 |
| PRODUCT_UNDER_ROOM_LIGHT | 当前商品在固定暖灰柔光下仍准确呈现的色彩/纹理；不改灯位，不把白、蓝、黑、棕等颜色统一染成旧黑灰。 |
| THIGH_FABRIC_ADAPTATION | 0.25秒捏同侧大腿外侧、0.55—0.85秒停、1.05秒松的动作幅度。只轻提本款现成余量；宽松款可自然形成垂褶，贴合款缩小幅度，不演示未知弹性。保留手、部位、方向和时间。 |
| LEG_MOTION_AT_WEIGHT_SHIFT | 换重心时本款裤管与裤脚的自然受力。只有图片显示长裤堆叠才写堆褶；直落/短裤/束口按可见实物处理，不添加旧款特征。 |
| FRONT_WAIST_TOUCH_TARGET | 前腰略偏画右、真实存在的接触位置。没有可见钮扣时写“前腰中部略偏画面右侧”，不添加钮扣。 |
| WAIST_CLOSURE_STATE | 按可见结构写“腰头保持原样”等。只在图确有钮扣时提钮扣保持扣好；没有证据不写内部拉链。 |
| WAIST_STRUCTURE_CONTINUITY | 保持实际腰头与已确认结构稳定。纽扣/门襟/腰袢/袋口等按本次图取舍；不解衣、不打开门襟、不制造腰围大幅形变。 |
| LEG_MOTION_AFTER_STEP | 后退落脚时当前裤管/下摆自然回落。只有本款确有堆叠才写脚踝堆褶，不自动把所有裤子变成长堆叠款。 |
| ENGLISH_OUTFIT_TITLE | 一句短且自然的美式英文穿搭标题，沿用“Outfit check: ….”结构，如品类/颜色足够清楚就据此填词；不加未证实性能、品牌、优惠或购买引导。去掉旧Black-wash denim，除非新款本就符合。 |
| PRODUCT_FINAL_ANCHOR | 结尾的一句当前商品核心可见一致性要求，复述当前颜色、轮廓和一两个真实结构；不是旧款固定签名。 |

## 最小动作适配的范围

固定顺序、起止时间、机位、走位、视线、表情、手别和手的路径。仅让动作接触新商品真实存在的部位，改变局部捏布幅度与受力结果。腰沿轻整与无字内裤边轻整理仍为原设定，不因为图片没有弹力信息而改成弹力演示。较高腰商品自然遮住白色内裤边时，不为强行露出而拉低商品腰位；这一必要遮挡适配不得改变整套构图与动作。若款型使原接触点不可见，在同侧最近可见裤面/腰沿完成相同轻整，不增加展示动作。

同一镜头内衣物褶皱由手和腿的接触驱动，背景不抖动、不扭曲，鞋着地后稳定。较宽裤管允许自然摆动，不沿用旧版“不变阔腿”的限制；新图有破洞、工装袋、纯黑、蓝色或束口时如实保留，不能把旧稿中的排除项当成本Skill通用禁令。

## 输出边界

保持完整模板的段落顺序与颗粒度，所有固定段落直接保留。中文只作提示词说明，成片只出现填好的英文标题。不要增加口播/歌词、转场、CTA、标志或平台控制参数。不要在最终提示词中出现“保持原背景、动作同原视频、看本会话、见附件原音频、参考包内视频”等外部依赖，也不要交付只包含替换差异的补丁。

正常只输出一个填好的完整text代码块；必要适配已写进动作正文，不另写长分析。缺图/目标不明确的关键问题应简短提出；当前明确要求修改固定项目时优先执行，并说明变化即可，不能静默变成另一套方案。
