# 镜前裤装

以本包完整模板换款，交付一段可整体复制的中文AI视频提示词。生成平台只接收本次新产品图和提示词。

## 每次调用

1. 读取本包 [完整提示词模板](references/prompt-template.txt) 和 [替换规则](references/replacement-rules.md)。实际查看用户本次上传的所有产品图及商品说明；按真实上传顺序和视角绑定图片，不固定图数。
2. 根据当前商品证据填满模板中的全部替换位。只改商品描述、产品对应英文穿搭标题、商品在室内光下的呈现及必要的局部动作适配（含新款腰位对原无字内裤边的真实遮挡）；模板其余内容逐段保留，不总结、缩短、重写或增加镜头。用户本次明确提出的修改优先。
3. 直接输出一个完整的text代码块，顺序、段落标题和详略沿用模板；输出不能有替换符、原SKU、历史商品或“同原片”等指代。默认不附对标拆解、商品报告、备选版本或新创意。关键输入清楚时直接完成；只有无法确定目标商品、图中多个款式冲突或品类使固定动作无法适用时，才提出一个具体问题。
4. 自查只需新产品图＋文本就可执行，手机仍遮脸、画左持机/画右空闲、全片一个镜头，六个时间段连续到10.10秒；字幕与配乐不被产品图或原视频带偏。

## 不可随换款改变的基线

- 约10.1秒、9:16；卧室床与衣柜之间的狭长过道、镜框/地面/暖白灯线布局、暖灰室内光。
- 同一约27岁成年男模的文字身份、白色贴身短袖、米白鞋、金饰和固定纹身；图中模特只提供商品穿着信息。
- 全身镜面自拍→轻捏同侧裤料→换重心→走近→轻整前腰→后退→倾头抚腿结束。六个镜内阶段不是六次切镜；保持所有已写时间点和停顿。
- 视线看手机，手机遮鼻口，画左持机手与画右空闲手不互换；保留模板全部姿态、表情和镜头因果。
- 无对白/口播/画外旁白。只有一句自然美式英文穿搭标题持续0.00—10.10秒；字位、字号观感、描边与持续显示方式保持模板。
- 保留声音段落全文：约100 BPM、四拍、短低音/轻鼓/短和弦/无词哼唱及固定强弱走势，不引用外部音轨，也不改成英语口播或有歌词演唱。

## 证据与归档边界

[最终原稿](references/approved-prompt.txt)完整保留本会话最后交付的示例商品版本，仅供用户要求核对/恢复原稿时读取；日常换款以模板和新图为依据，不把归档中的颜色、版型、后袋、堆褶或禁用颜色当成新商品事实。

原对标视频（公开版未附此文件）按用户要求保存在包内，仅作归档，**日常调用不必打开、重新分析或上传它**。不得把归档视频当成新生成任务必须提供的输入，也不能把其中原人物、浅蓝裤、品牌腰边、歌曲覆盖回文字模板。

[版本与来源](references/provenance.md)记录确认来源、原稿与视频校验值。视频效果通过来自用户本次确认；封装与换款验证不等于再次生成验收。未经本次明确请求，不调用图片/视频生成或发布服务。本Skill不依赖其他Skill、原会话、联网、脚本或模型。
