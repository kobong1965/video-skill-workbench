# 西部牛仔裤

将用户当前上传的新裤子图代入已确认方案，直接交付一个可整体复制的中文提示词代码框；成片讲解和字幕保持美式英文。用户在封装时确认本会话最终方案已生成并通过；本 Skill 保存该方案，不重新创作或声称每次换款都已生成验收。

## 每次调用

1. 完整读取 [换款规则与变量定义](references/product-adaptation.md) 和 [完整执行模板](references/prompt-template.md)。仅使用当前图片及当前用户提供的商品资料填入全部变量。
2. 保持模板其余文字、标题顺序、人物、背景、光线、镜头、转场和时间；只调整产品事实、与产品直接接触的动作和对应英语文案。用户本次明确要求的调整优先。
3. 输出一个完整的中文生成提示词代码框，包含统一人物、当前商品图片用途、全部12镜头、转场、五段英语讲解、字幕内容和时间、声音及连续性要求。不得输出待填变量、节选、模板文件路径、“其余不变”或只给产品替换表。默认不附长篇分析。
4. 产品图清楚就直接完成。仅商品身份有冲突、关键结构无法辨认且确实影响执行，或用户想把不适配的非裤装商品套入本方案时，问一个必要问题；普通的未知材质/弹性无需询问，不写相关卖点即可。

## 固定方案边界

- 约15.03秒，画面流终点15.033秒；9:16，目标720×1280、约30fps。若生成入口仅支持整数15秒，仅将最后走近缩短约0.033秒。
- 固定同一位约28岁、浅暖小麦肤色、灰绿眼、深棕短发、无胡须的成年男士；奶油白西部帽、深炭蓝双胸袋衬衫、棕皮带与无字金属大扣、棕牛仔靴。第1/7/8镜已卷袖，其余到腕。产品图里的人脸、上衣、鞋和背景不定义这些设定。
- 完整保留12镜头：木门廊推进下移→停车场正面→店外背面走远→靴店内→围栏双腿近景→住宅门廊→停车场蹲起→停车场侧后→靴店走出→围栏左腿近景→牧场走近并下移→白栏杆门廊收尾。
- 硬切3.200/4.367/4.867/10.900秒；7处叠化保留模板所写范围。开头和第11镜的构图变化是镜内连续过程；第7→8镜有叠化。
- 同一中低男声自然美式英文讲解，露脸时讲话口型，背面/裁脸时延续同一声音；五个窗口与字幕一致。无BGM和新增强化拟音，14.14秒后收音、14.60秒起静音。

## 独立性与商品检查

新提示词必须仅靠当前新产品图和文字成立。不能要求生成器读取本 Skill、原视频、历史商品图、原音频、原会话或额外人物图。不要出现“同原片”“参考原音乐”、不存在的 @Video/@Audio，也不能把包内原视频当作本次上传素材。
输出前逐镜检查旧商品颜色、洗色、毛边、拼片、后袋、直筒/修身等是否确有当前证据，确保产品名、镜头描述、讲解、字幕及连续性段落一起更新。没有图证或资料支持的成分、弹力、耐用、价格、销量、优惠和功能不写。
