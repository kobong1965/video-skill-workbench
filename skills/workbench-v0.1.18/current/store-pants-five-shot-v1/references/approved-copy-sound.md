# 04 文案字幕与声音时间表

## 口播

全段无新增人物对白、对口型或画外旁白。原音轨的英文节奏人声属于歌曲/歌词的离线辅助证据，不能当作商品口播。新音乐使用无词人声切片，不沿用原歌词、歌手或旋律。

## 新音乐与动作声音（生成近似）

| 时间 | 要求 |
|---|---|
| 0.000 | 配乐直接进入，不等待片头；约98BPM低频短循环，中速、有弹跳感 |
| 0.82 / 2.07 / 3.33 / 4.54 / 5.77 / 7.01 / 8.24 / 9.49 | 在附近安排较强节奏脉冲，依据原音轨频谱瞬态位置近似；这些不是人工听审确认的原曲鼓点 |
| 四次硬切1.867 / 4.167 / 5.867 / 7.433 | 配乐保持连续，不能每镜重启；不增加转场whoosh |
| 4.23附近 | 可有小打击音，在4.167切近景后稍迟呼应 |
| 7.63附近 | 可有小节奏点呼应抬左膝，不能改成机械卡点舞 |
| 9.8—10.2 | 配乐明显减弱约8dB，削弱低音/鼓，无词切片退出是本方案选择，并非源片确认的人声停止点 |
| 10.2—12.63 | 轻量节奏尾部，保持仍有声音，结束随画面截断，仅极短防爆音收口 |
| 提布/抚平、手机入袋 | 不做强调型音效；如生成衣料接触声，应极轻且低于配乐 |
| 约8.2落脚与11.25后走近 | 仅可有很轻的靴底接触声；源片独立脚步未确认，这属于克制的合成选择 |

配器为本方案选定的圆润合成低音、短促底鼓、简短拍手/军鼓、稀疏高帽及低声无词男声切片。原片具体乐器、流派、声线性别、曲名未直接听审确认。原轨10秒后测量上明显收弱，是可保留的结构；具体衰减曲线不确定。

文字无法确保生成同一首歌、同一旋律、相同字幕字形或逐帧时间。若需要原曲精确一致，需要原音轨或后期配乐；当前稿完全符合仅上传提示词和产品图的使用方式。
