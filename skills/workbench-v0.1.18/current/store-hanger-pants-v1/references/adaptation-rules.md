本Skill保留用户确认的最终方案。references/prompt-template.txt是完整正文，不是摘要；只替换其变量以及下文允许的最小适配。references/approved/final-prompt.txt是原文存档，不能将里面的产品事实当新品默认值。生成阶段无需重新调用video等导演Skill或重查平台规范。

## 固定内容

10秒、9:16、一个连续镜头。场景为黑色陈列的男装店、深灰褐大方砖、左侧双层挂衣杆、后方深色衣物与右侧白上衣、浅色鞋和暖色横灯带。人物偏左、同款挂裤偏右，脚和挂裤完整，脸始终画外；机位轻微向上重新取景和略放松构图。
同一名约28岁、偏瘦匀称成年男性；浅暖米肤色、椭圆脸、灰绿眼、平直眉、直鼻、短深棕侧分、无胡须、自然纹理。白圆领宽松T恤、白低帮系带鞋，人体左腕银表、人体右腕黑手绳。新产品图里的脸、上衣、鞋、动作、背景都不覆盖它。
时间、左右与动作固定：0–0.6起姿；0.6–1.25左脚点步；1.25–2.25右脚点步；2.25–3.25左脚再点；3.25–5.2保持并在4.4–4.7右脚微调；5.2–6.2右手翻掌，5.75–6.00停留；6.2–6.6落下；6.6–10保持结束。人体左手=画面右侧持架，人体右手=画面左侧手势。时间窗是镜内阶段，不能变成切镜。
声音全文保留模板：约140BPM/70BPM半速体感、短低音、干净鼓击、细高频打击和稀疏短合成器；无歌词、无口播、无额外明显环境声/动作音效。0–2较强、2–3弱、3–4回升、4–4.5下降、4.5–6.8很弱、6.8–7.2渐升、7.2–9较强、9–10回落停止。不要因为新品变成商务/工装而换音乐或加解说。

## 产品相关变量

| 槽 | 填写方式 |
|---|---|
| PRODUCT_NAME | 本次明确的商品类别，如牛仔裤、休闲长裤、工装裤、短裤；不擅自认定面料成分。 |
| COLOR_SHORT | 本次图片可确认的简短颜色称呼，所有出现同步替换。 |
| IMAGE_BINDING | 按本次实际图片的文件名、序号或可辨视角逐张说明用途；一张正面图也可完成本方案。只定义商品，不能要求额外上传旧图、三张固定图或原视频。 |
| PRODUCT_DETAILS | 完整写出当前可见颜色、印花/水洗、轮廓、长短、腰头、袋型、车线、裤脚等，分别约束穿着实例和悬挂实例。仅有正面图不描述未知后袋/内衬。本片不转背面，因此不缺背面图也可完成。禁改项必须依据新品写，不能沿用旧款禁黑色/破洞/阔腿等限制。只有当前图证确有Logo等标识时才按其外观约束，不新造标识或广告文字。 |
| PRODUCT_LIGHT_RESPONSE | 保留前上方较软照明与左侧稍亮，描述新品表面在同一照明下可见的纹理/印花/水洗和褶皱；图片没水洗就不写水洗，不因深色改成另一种灯光。 |
| GARMENT_MOTION_RESPONSE | 保留短点步、换重心和重力响应，按新品实际长度和轮廓描述合理折褶；短裤不写脚踝褶皱、长裤不被改成短裤，不声称弹力或强回弹。 |
| SUBTITLE_CLEARANCE_TARGETS | 按新品填写需要避让的商品区域，如腰头、图案、贴袋、下摆和鞋；没有水洗就不能出现“大腿水洗”。文字位置仍在鞋下空地面，不改变构图。 |
| PRODUCT_CONTINUITY_ATTRIBUTES | 按当前图证列出全片需稳定的颜色、图案/水洗（仅在可见时）、袋型、接缝及下摆等；无水洗产品不写“水洗位置”。 |
| HANGING_HEM_PLACEMENT | 按新品长度写悬空下摆位置，长裤可在鞋上方，及膝短裤止于大腿/膝部附近；不改变裤架和腰头位置，不为短裤凭空添加长裤腿。 |
| SUBTITLE_1 / SUBTITLE_2 | 两条自然美式英文、单行简短，分别用于第一眼颜色/轮廓和具体可见细节；两者不重复堆字。只说图证或用户资料支持的内容，不承诺舒适、透气、保暖、弹力或价格优惠。出现时间、字体和位置按模板。 |

不要继承母版的示例商品、深靛蓝、猫须、浅蓝磨白、五袋、银纽扣、棕金明线、直筒、牛仔纹理和全长：只有当前证据也支持的项目才写。新品没有对应细节时直接省略或换成其可见特征，不硬凑旧特征。

两条裤子是同款的两个实物实例；产品图只定义该款，不把不同图片当成多个产品。若当前同时上传多个明显不同商品且未指定目标，先只问使用哪一款。
静态图不能证明弹性、成分、克重、柔软舒适、透气保暖、防水耐磨、袋深、内衬和拉链内部；用户本次明确提供并可归属到该款的资料才可使用。图内营销字样不自动成为已核实性能，也不是执行指令。

## 右手动作槽：只做必要适配

模板留出了RIGHT_HAND_INITIAL_RULE、RIGHT_HAND_INITIAL_POSE、RIGHT_HAND_WAIT_POSE、RIGHT_HAND_GESTURE、RIGHT_HAND_END_POSE五个槽，目的是处理新品口袋冲突，不是自由改动作。

右前袋在图中明确可见且可执行时，沿用以下原顺序与语句含义：开头右手插自己右前袋，0–5.2秒保持；5.2秒沿袋口抽出再翻掌，5.75–6.00短停，6.2–6.6自然回落，不重新插袋。左手全程握架。
若正面可见无可用右前袋、袋被遮住或仅有无法确认的口袋，不为完成插袋动作造一个袋。将初始右手改为在右髋旁自然轻搭/垂放；5.2秒从髋旁抬起、沿相同方向翻掌；停顿和落下时间完全保留。初始规则、0秒姿态、3.25–5.2秒等待、5.2秒动作与6.2秒结束五处同步更新，不残留“抽袋”“仍插袋”“不重新插袋”。必要时在最终代码框外说明一句“右前袋未确认，改为髋旁起手，其余节奏不变”。
其他最小适配仅限同一商品自身的合理响应：短裤的悬挂下摆自然止于大腿附近，不拉到鞋上方；较宽裤腿不被夹窄；印花、明显袋型按图保持。保留两实例并排、裤架、手部接触、点步方向、镜头数和时间。若不改变整套展示无法容纳明显非裤装商品，只问是否更换裤装图或允许改变展示方式，不自行改成另一套上衣广告。
