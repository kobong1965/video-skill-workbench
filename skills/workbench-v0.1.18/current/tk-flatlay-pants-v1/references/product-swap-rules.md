# 产品换款与文案替换规则

## 产品事实从当前输入开始

只看本次实际可读的新产品图与本次明确提供的资料。内部先列可见事实，再填模板；不要求用户先填写完整商品表。多张图先判断是否同款，明确矛盾且影响生成时才问。正面图足够，缺背面时不补后袋特写。

颜色按可见主色与局部明暗写，不把布料阴影当印花。区分整体轮廓、穿着堆叠和产品结构：褶皱不等于抽褶设计，脚踝堆叠不等于束脚，白色内搭边缘不等于拼接腰头。闭合门襟外观不等于已确认拉链。

可以替换：裤子类别、颜色、洗色/图案、长短、轮廓、可见袋形与数量、扣子、腰袢、明线、装饰、裤脚。棉含量、弹力、柔软透气、耐磨、防水、加绒保暖、舒适度、价格销量等必须有本次明确资料才写。不能从归档迷彩裤或示例商品蓝色水洗牛仔裤继承这些特征。

图中的模特、纹身、姿势、上衣、鞋子及背景只作无关画面忽略。最终片固定无人平铺＋黑T恤＋黑色骨骼图案拖鞋，不能把产品图里的其他鞋款替进来。

## 模板槽位

| 槽位 | 填入内容 |
|---|---|
| product_name | 简短而具体的当前商品名称，例如颜色＋类别；全文同款一致，不强行称牛仔裤。 |
| product_reference_roles | 逐张描述本次实际上传图及它只定义的商品属性。只有1图就只引用1图，用实际图号/内容，不沿用归档图名；不需要新人物图。 |
| product_facts | 当前可确认的颜色、轮廓、腰头、口袋、纹理、装饰与裤脚；不可见细节用不展示处理。整段必须明确全片正面朝上不翻面。 |
| flatlay_state | 按当前裤长与形态平放：腰头自然闭合、两腿略分开，布料贴地；穿着堆叠转为松散自然褶皱，不撑成立体腿形。没有普通前扣时不写扣合；短裤可缩短物件长度，保留相机和摆放关系。 |
| light_on_product | 当前颜色和纹理如何在固定柔光下保持可读。没有牛仔纹或水洗就不写牛仔、水洗。 |
| primary_visual_detail | 第二镜全景停顿要读清的已有外观，简短名词短语。 |
| front_detail_focus | 第四镜的腰头/前片特写中心；只列当前可见真实结构。若无圆扣、弧袋或对比线，就换成实际腰头、褶线、袋口、织纹等，不补造。 |
| leg_visual_detail | 第八镜看见的裤腿可见细节，保持裤长与比例真实。 |
| surface_and_structure | 全片必须保持不爬动的当前表面和结构，例如颜色与接缝、条纹与口袋。 |
| detail_occlusion_guard | 字幕避免遮住的当前商品关键位置，不能机械残留旧圆扣/前袋。 |
| vo1–vo5 | 下表的五段完整美式英文台词。 |
| vo1_direction–vo5_direction | 对新台词适用的重读词、短停和尾音，不引用旧台词中已删除词汇。 |
| subtitle1–subtitle4 | 下表的四条完整英文广告摘要。 |

模板槽位只是编写工具；最终输出必须全部填成确定语句，不输出花括号标记或在这里填写。

## 五段英文旁白与四条字幕

保持口播为同一个新成年中低音美式英语画外声音，无人物对口型。语气轻松聊天，不改成强销售喊话。保留母版的短句和段落功能：

| 台词槽位 | 固定窗口 | 功能与字数参考 |
|---|---|---|
| vo1 | 0.000–1.420秒 | 4词左右的外观吸引，可用These pants stand out.；准确是牛仔裤才用jeans。 |
| vo2 | 1.740–2.380秒 | 2词左右短问句，可保留See it?。 |
| vo3 | 2.840–3.860秒 | 3词左右点出一项明确可见特征；不能无依据保留That blue wash.。 |
| vo4 | 4.920–7.400秒 | 6词左右搭配句，保留Black tee与轻松穿搭表达；非牛仔裤不能说denim，颜色也同步换。 |
| vo5 | 8.660–11.320秒 | 7词左右温和CTA，保持Like the look? Check out these pants.结构，可按实际品类替换pants；不说已挂链接。 |

保持母版的非产品措辞：vo2继续使用See it?；vo4保留Black tee, … . Easy outfit.的搭配句式；vo5保留Like the look? Check out these … .的问句和邀请。不要仅为润色把Easy outfit改为Easy pairing，或增加新口号。字幕同样保留母版句式和标点：These … stand out.／See that …?／Black tee. … .／Check out these … .，只替换产品类别、颜色和可见特征，不换成加号排版或新的CTA句型。字数是自然语速参考，不能为了凑字造卖点，也不能硬塞长台词。每段写全台词和对应重音，句间窗口保持安静。

四条字幕依次是外观吸引、第二行可见细节提问、黑T恤与裤装搭配摘要、CTA。固定入出点与行数：
- subtitle1：0.000–4.067秒主行。
- subtitle2：1.967–4.067秒主行下方加一行；前两条合起来最多两行。
- 4.067–5.433秒留白。
- subtitle3：5.433–8.867秒单行。
- subtitle4：8.867–12.867秒单行。

它们是广告摘要/独立文字，不是逐字字幕。英文短句一行放得下，不能扩成大字幕墙，不用中文、emoji、价格、虚假按钮。台词/摘要/商品外观要相符；没有洗色就不能在另一处残留wash。

## 保真与独立执行

固定模板的场景、8镜头文字和声音说明必须完整输出。不能用“其余不变”“同原稿”“沿用该Skill”“参考原视频”省略。最终生成器只会看新图和最终提示词；不得引用包内MP4、原音轨或归档产品图。后台归档无需用户重复上传。

只对产品不适配点做最小调整，如无前扣则改观察现有腰头、无口袋则改接缝细节；镜4仍为腰部前片近景、镜5仍为T恤、镜6仍为鞋、结尾仍全套平铺。没有触摸动作就不加手，也不加摩擦拉链音。用户未另改时不要为短裤/不同颜色重排镜头或延长时间。

音轨方案已完整写入模板。常规换款直接沿用这套声音设计，不再次推测原曲、做BPM识别或承诺原歌曲精确复原。输出提示词只要求执行，不保证逐帧、字幕或外观绝对准确。
