# 视频脚本7：厨房低机位裤装

将用户已经实际出片并确认通过的一套方案用于新裤装。默认只接收新产品图及用户可选说明，输出可整体复制的中文 Seedance 提示词。镜头方案已确定，直接做产品适配，不重新分析对标视频。

## 每次调用

1. 读取 [已确认的完整原稿](references/approved-prompt.txt) 和 [换款规则](references/reuse-map.md)。它们随 Skill 一起保存，无需访问原会话、原视频或原始文件路径。
2. 实际查看本次产品图。只把图中可确认的颜色、纹理、轮廓、裤长、腰头、口袋、车线、裤脚等作为商品事实；用户文字可补充材质、功能等资料。一个清晰正面图即可开始，不强制三张图或背面图。商品不清楚、图片包含不同款而没有指定，或输入不是可沿用裤装动作的产品时，集中询问影响执行的问题；清楚可用时直接输出。
3. 以原稿为底稿执行换款，按照 reuse-map 修改所有涉及旧产品的内容及英文文案。保留固定的场景、人物、搭配、机位、光线、镜头边界、动作先后、停顿、声画结构和结尾。商品证据优先于旧商品描述；仅做必要的局部动作适配。
4. 用本次实际上传的产品图数量、文件名或明确的“本次产品图”指代重写商品图用途。图片只定义商品；人物、纹身、背景、拍摄姿势和鞋子不能从商品图带入。没有上传背面图就不编造后袋、皮牌、内衬或其他不可见细节。引用图片名称不等于让它出现在成片中。
5. 输出完整提示词，保留原稿的商品、人物、场景与光线、11镜时间线、英文旁白、画面文字、声音及连续性这些部分。每镜写全起始状态、动作过程和结束构图，保留具体的手、脚、方向、速度和停顿。只给商品差异表、半截脚本或“其余同原稿”不能完成任务。

## 固定方案

- 平台沿用原稿 Seedance 2.5；23.50秒、9:16、写实手机观感，720×1280为目标输出尺寸。这些是制作目标，不伪造平台参数或承诺入口一定支持23.5秒。
- 11镜、10次硬切，镜头时间见 reuse-map。全片同一厨房餐区、同一成年男性、深色无品牌连帽卫衣、白鞋浅棕底。
- 固定低机位略仰，相机不推拉、不变焦、不摇移；由人物前后移动改变取景。头脸全程画外，声音是成年男性画外讲解，无口型。
- 前左侧宽面柔光；保留地板、白墙、岛台、两张红棕高脚凳及右上黑色小吊灯的空间关系。
- 保留手持独立说明卡镜头。卡片的两行内容随商品改写，不编造价格、条码、品牌或工厂吊牌。
- 中文生成提示词，美式英文口播与独立标题字幕。旁白沿用原时间窗口、说话方式和句子作用，按新商品可确认特征重写，词量接近原稿，不能用异常快语速硬塞。
- 一条固定标题字幕，位置、字号观感和出入节奏沿用原稿；不自动添加逐句或逐字字幕。
- 无BGM；极低均匀室内底噪，无强化布料、脚步或转场音。旁白23.10秒结束，画面23.50秒直接结束。

用户明确要求改变时长、画幅、配音语言或其他设定时，以本次要求为准，简短说明偏离默认方案的调整；不要暗示调整后的版本已经实测通过。不要自行把23.5秒压成15秒。

## 交付

先用一句话说明“使用视频脚本7，已按本次产品图换款”，必要时补一句重要适配。随后只放一个可整体复制的 text 代码块，内容是完整的新产品生成提示词。除非用户要求，不重复交付原片分析、模板说明或长表格。 代码块只包含交给生成器的内容，不加入 Skill 路径、方法归属、校验记录或其他制作说明。方法归属已在随包 reuse-map.md 中保留，无须拼接进每次生成提示词；需要引用时放在代码块外。

交付前核对：

- 11个镜头及全部时间边界齐全；固定场景、人物搭配、动作顺序和声音结构保持。
- 在商品颜色、版型、细节、镜5/6/8/11、纸卡、旁白、标题和连续性段中完成一致替换；不得残留与本次商品不符的 示例商品、黑灰水洗、偏窄、堆叠或后袋花纹。
- 原稿针对旧商品的“不得有工装袋、破洞”等限制不是新商品的事实：新产品确有的结构应保留，禁止的是未获证实的新增结构。
- 输出中没有未替换的占位符，没有“动作同原片”“保持原背景”“其余沿用”等依赖未上传素材的指代；不引用不存在的 @Video、@Audio 或人物/场景参考图。
- 没有为看不见的部位补造细节，没有未经证实的弹力、面料、舒适度、性能、价格、优惠、销量或库存承诺。
- 最终提示词独立成立，生成器只需本次产品图和提示词。此次调用只编写提示词，不调用生图、生视频或发布服务。
