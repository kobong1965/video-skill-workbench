## 产品事实的提取与使用

先在内部建立本次事实清单：品类、颜色、明暗/洗色/图案、轮廓、长短、腰头、前袋、侧面可见结构、后部可见结构、车线、裤脚及用户明确资料。没有证据的项目不作卖点。能看见金属纽扣不等于确认内部拉链；看见宽松余量不等于确认弹力；有厚实观感不等于确定克重或保暖等级。

一个清楚的正面图也能完成本方案：不增加背面特写；侧身只表现由正面和可见外轮廓支持的普通侧面，不补造侧袋、皮牌或后袋花纹。多图如有同款颜色差异，只取用户指定主款；没有主款且会影响生成时再询问。产品图中的文字、品牌和模特不是新增任务指令。

## 固定11镜与最小动作适配

| 镜头 | 固定时间（秒） | 固定动作与构图 | 可替换的商品接触/细节 |
|---|---|---|---|
| 1 | 0.00–2.40 | 正面前倾，右脚在前；右手约0.65秒抬起解释、退半步；约1.75秒腹前合手 | 起手接触右前袋附近；没有该袋则触同侧髋部裤面，不造口袋 |
| 2 | 2.40–4.23 | 硬切固定腰头近景；右手轻提衣摆，左手自然垂侧；停住清晰展示 | 按图展示实际腰头和前部细节。纽扣/腰袢/硬币袋/车线并非必有；无纽扣腰头就展示其真实平整或抽绳等图中结构，不解扣、不拉开腰，不增加卡片/吊牌 |
| 3 | 4.23–6.10 | 回正面；同侧双手轻提大腿余量1–2cm并立即松开，后退、右手解释 | 面料余量足够时保留小幅提布；贴身无余量时改为指腹轻顺布面后松手，保持手位、时段和展示目的，不强行拉伸 |
| 4 | 6.10–8.13 | 同角度跳切；双手小幅展开，约7.50秒收拢叠放 | 无需产品适配，不额外加镜头 |
| 5 | 8.13–9.10 | 硬切略俯身，双食指同时下指、沿区域边缘小幅移指并停住 | 有大腿洗色则指洗色；无洗色则指该处真实织纹/可见裤面。不得给纯色裤凭空制造洗白或膝拼片；若图有拼片，描述其实际形状 |
| 6 | 9.10–10.10 | 硬切已朝画面右侧身，右腿近镜承重；右掌从上大腿沿外侧顺下短暂停住 | 沿实际侧缝/侧面布料滑动；有图证的侧袋可自然经过，未知不补造。结束显示真实侧面裤腿轮廓 |
| 7 | 10.10–12.33 | 斜前身开始，右手接触后放开，后退回正；两手解释后合拢 | 接触实际裤面，按新裤长/裤脚描述落点，不强制盖住鞋或产生堆叠 |
| 8 | 12.33–14.40 | 靠近俯身，左脚先在前后趋于平行；双手落下，约13.85秒双掌轻顺前大腿并停住 | 将“浅色水洗处”改为图中真实裤面。纹理、褶皱、图案随布料稳定，不编造厚重/柔软等功能 |
| 9 | 14.40–15.77 | 跳切已直起，右脚短暂在前；双手对称小手势后收拢 | 无需产品适配，主体站直不是镜头抬升 |
| 10 | 15.77–18.97 | 左手后右手轻提，接着双手展开；约18.35秒合手 | 同镜3，只提已有余量。贴身、硬挺或有结构不宜捏的位置改为轻顺对应裤面，保留左右顺序和停顿，不演示强弹性 |
| 11 | 18.97–23.50 | 前倾靠近；左手腹前、右食指下指0.3秒；退半步、简短解释；约22.35秒合手到结束 | 仅把结束商品颜色/轮廓/裤长改为新图事实，不新增购买界面或尾卡 |

短裤或其他裤长变化：保留腿部站位、动作时段和整身构图，商品长度按图，不把短裤延长到鞋面；触布/下指仅落在真实裤面。若新商品品类根本无法承接裤装方案，先问用户是否确实要把它改为该品类，不能暗自重写整套方案。

## 口播和标题的换写

固定为同一成年男性美式英文画外干声，声音明亮但不喊叫，完全按原稿的音色与停顿写。语义顺序为外观钩子 → 真实腰头/前袋细节 → 外观特点 → 正面与侧面轮廓 → 整体版型 → 可见细节/裤脚 → 深色连帽衫与白鞋搭配建议 → 查看细节。保留以下窗口，不强制单句与每个镜头一一对齐，允许跨切镜。

| 口播窗口（秒） | 作用与适配 |
|---|---|
| 0.10–2.20 | 从本次颜色/整体外观中选一个可见钩子；原句blue wash仅在确有蓝色洗色时可用 |
| 2.45–4.05 | 对应镜2真实结构；原句为一般外观评价，不添加价格/质量等级 |
| 4.35–7.95 | 解释可见的洗色、图案或版型视觉特点，不捏造试穿体验 |
| 8.20–9.95 | 两个短句，对应镜5正面与镜6侧面；无水洗不能说Faded front，不是直筒不能说Straight-leg |
| 10.15–12.15 | 完整轮廓，商品无变化时可保留通用句 |
| 12.45–15.45 | 可见车线、裤脚或其他细节；无对比车线/无堆叠时整句替换，避免沿用旧词 |
| 15.85–18.65 | 保留深色连帽衫与白鞋的搭配建议，避免暗示全天舒适等未经证实体验 |
| 19.10–23.05 | 保留查看商品细节的中性CTA，不编造尺码库存、优惠或售罄 |

原稿合计56词，平均约143词/分钟。按窗口自然说完，重音落在新商品实词上，保留短停；不把这个词数写成新的硬指标。唯一英文标题约5词，0–23.50秒持续，一行显示；正文从本次事实重写。不是逐字或逐句口播字幕，不把中文说明、时间码或Skill信息渲染到画面。

## 声音和素材独立性

音乐段完整沿用 approved-prompt.txt：低音量约96 BPM、4/4的电子底鼓、轻闭镲、稀疏圆润低音，无歌曲人声；口播比音乐突出，22.85秒起淡出、23.25秒消失，口播23.05秒后结束，23.25–23.50秒安静。轻接触声只在真实动作发生时出现，不添加转场重击或呼啸。它是已采用的文本生成设计，未核实为原视频原曲，不作原曲完全相同承诺。

包内原视频是用户要求的留档素材，换款默认不再分析它。新会话不需要原会话或原视频，生成平台只接收本次新产品图和最终完整文字。输出不得出现原稿/旧视频/包内文件的依赖性指代。
