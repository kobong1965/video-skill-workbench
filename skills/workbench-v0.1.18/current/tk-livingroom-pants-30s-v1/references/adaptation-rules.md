# 客厅裤装30秒的产品替换规则

## 唯一执行入口

执行references/prompt-template.txt，不直接复制assets/baseline里的旧商品原稿。母版中的{{字段}}只供Codex在内部替换，最终交付必须全部写成实际文字。固定段落保持原句及顺序，不能只给“固定部分照旧”的简版。

## 本次产品证据

按本次实际图序绑定每张图：定义正面、背面、局部结构或穿着轮廓等。只有一张就只写一张，不建立不存在的“产品图2/3”。产品图只定义商品；忽略图中人物脸部、上衣、鞋、姿势和拍摄背景。多张若明显不同款或颜色且本次没选定，先问清本次款式。

内部先确认：产品类别、主色与色差、裤长/腿口、宽窄及形状、可见面料表面、腰头及扣合、前袋/后袋/侧袋、车线、图案/水洗/破洞。仅记录可见信息；“看起来像”不升级为成分、弹力、保暖、耐磨或舒适承诺。图中缺少信息不表示产品一定没有该结构。

归档中的示例商品、中蓝、直筒、大腿渐变、棕黄线、五边形后袋、单金属扣都是旧例，不构成新款默认值。原对标的其他品牌、25美元、折扣、销量、售罄、身高体重尺码同样不能继承。

## 母版字段

| 字段 | 填写方式 |
|---|---|
| PRODUCT_KIND | 当前商品名，如黑色长裤、米色收口裤；不能一律写牛仔裤 |
| PRODUCT_REFERENCE_BLOCK | 实际上传图用途+本款全部已证实外观+连续性与未知信息约束；整段完整写出，不引用本规则 |
| PRODUCT_COLOR | 本款可确认颜色，仅改商品颜色句，不改固定室内光色 |
| SHOT1_TITLE | 当前款提腰、整理或扣合、正面展示，不能对无扣裤仍命名为扣合 |
| WAIST_START | 本款已穿在腿上、腰头略低于正常腰位；无扣裤不出现未扣或开门襟状态 |
| SIDE_OUTLINE | 本款侧面真实轮廓及腿口关系；短裤不能仍写膝部到长裤脚的线条 |
| CLOSURE_ACTION | 有可见单扣才保留双手扣合。松紧腰/抽绳/看不见闭合方式时，用双手整理已有腰头，再松手；不编扣、拉链或内部结构 |
| FRONT_DETAIL | 镜3左掌轻抚下可见的实际颜色/纹理/车线；纯色无水洗就描述纯色与线条，不创造褪色或拉伸 |
| HEM_DESCRIPTION | 实际裤长、裤口和白鞋关系。只有图中明确可见时才写长裤轻堆叠；若仅确认长裤，写自然下垂与白鞋可见，不指定盖鞋、堆叠或露踝；短裤写真实膝上/膝下裤口和可见小腿；收口裤按图，不强制盖鞋 |
| BACK_START_FRAMING | 有背图沿用较近侧后角度；无背图只把此处换成较宽侧后构图，配合后轮廓不拍未知细节 |
| BACK_REVEAL | 有背图则逐项写证实的后腰/后袋；只有正图时保持同镜转身，给较宽后轮廓，不增加/数清/特写未知后袋、皮牌、装饰或结构 |
| BACK_END_STATE | 同上，写背面轮廓的结束构图，不能兜底回旧款双袋 |
| POCKET_GESTURE | 有前袋在可见袋附近开掌；无袋或未证实就把手势放在侧腰/大腿旁，不插进未知结构 |
| FINAL_PRODUCT_VIEW | 最后正面本款颜色、轮廓、裤脚及白鞋的具体可见状态 |
| PRODUCT_CONSISTENCY | 本款颜色、纹理、裤型、可见袋型、长度等不得跨镜变化；不列旧款特征 |
| EMPHASIS_WORDS | 根据本次实际11句英文设自然重音，不能残留wash、jeans、straight-leg等不适用词 |
| VO_01至VO_11 | 当前商品的完整11句英文口播 |
| CAPTION_01至CAPTION_11 | 与对应口播逐字同文，最多两行，按母版时间直接出入 |
| OPENING_PAUSE | 跟随新开头自然语义的短停顿；删除针对旧“wash”的说明 |
| CAPTION_03_TEXT | 当前第3句准确英文，用于镜3下方位置说明 |

其他内容固定，包括人物、穿搭、客厅布局、固定相机、光线、时间、动作次序、音乐及最后不加片尾卡。实际是非牛仔裤时将母版所有“牛仔裤”改成当前类别；与版型、水洗、袋或长度有关的残余旧词逐项检查。

## 口播与字幕

固定窗口：
01 0.10—4.05；02 4.35—7.50；03 7.78—8.94；04 9.10—10.58；
05 10.85—13.04；06 13.38—15.34；07 15.64—17.55；08 17.85—20.74；
09 21.03—24.03；10 24.36—26.53；11 26.85—29.62秒。

固定表达作用，替换产品事实：
01 口语问句引出当前外观与轮廓；
02 当前颜色及第二项可见细节；
03 贴合左掌抚腿的短句；
04 裤脚/腿口，必要时用下段线条；
05 侧面与背面轮廓，未知后结构不口播卖点；
06 保留T恤白鞋搭配句；
07 保留简短穿搭表达，按裤类改jeans/pants等名词；
08 配合衣摆放下再提起，保留其作用；
09 前部可证实细节；无袋不说pockets，无水洗不说fade；
10 再看轮廓；
11 保留温和查看详情和尺码的CTA，不许添加限时/缺货/优惠。

原句只有商品事实仍成立时才保留。总词量接近70词，各窗口自然能说完；不硬凑字数。字幕文字与新口播一致，重音和停顿跟随新句。没有口型/露脸需求。不要擅自变为无旁白或中文成片文案。

## 只做必要的动作适配

原腰头扣合不可执行时，仅改扣合为整理腰头；手部左/右、表所在手和镜头时间不变。无后图不是必须追问的理由：背面仅以远一些轮廓交代，不拍细节，也不把“未知”硬渲染成无后袋。需要保证特定背面结构而无证据时才询问。
无水洗时只替换抚腿目的和英文，不改镜3机位、左掌触点、轻抚及后退。短裤或收口裤只替换裤长及裤口动作语义，不拉长成原长裤。
不得因裤子可能有弹力而加拉伸、深蹲、跑跳；原方案仅普通提腰和轻抚。

## 最后核对

在脑中把当前产品证据与完整提示词逐镜匹配；所有商品描述、英文台词、字幕、重音、结尾和连续性段都属于同一新款。仅引用本次实际图片，不出现旧SKU/文件名/未上传背图、视频、音轨或本地文件路径。11镜及其时间精确沿用，镜内动作不能新增剪辑。模板所有字段均替换，输出包含完整固定场景/人物/音频段落，不能依赖其他文件才执行。
