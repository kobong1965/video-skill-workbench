## 每次调用

1. 完整读取 [换款模板](references/prompt-template.txt) 和 [替换与不变规则](references/reuse-map.md)。它们含全部场景、人物、九镜、音画及结尾要求，不依赖旧会话、安装源目录或其他 Skill。
2. 实际查看本次新产品图并结合用户提供的商品资料，确认颜色、外观纹理、轮廓、裤长、前后袋、腰头、车线与裤脚。只使用本次证据。清晰可用时直接出稿，不因未提供旧视频、旧音频、人物参考或三张齐全的产品图而追问。
3. 从模板逐项替换所有产品槽位，包括散落在各镜头、字幕、重音和连续性中的产品描述。保留其余正文及段落格式。缺背面证据、没有口袋或没有堆叠时，用 reuse-map 的局部适配，不把旧款后袋/蓝色/水洗/堆叠或禁止新品真实结构的旧限制带入。
4. 直接输出一个完整可复制的中文文本框。依次保留开头规格、素材用途、人物与服饰、裤子一致性、场景与光线、镜头1—9、英文字幕、声音、连续性与完成要求。英文口播和字幕按原窗口和句子作用改写；人物静默、成年男性美式英语画外旁白、无新增旋律鼓点的声音方式保持。不能只交差异表、模板或“其余同原稿”。
5. 发出前独立检查：实际图片引用正确；所有槽位已填；产品描述均有本次证据；九镜齐全、左右手与8次硬切无冲突；旁白与字幕一致，末行独立文字不朗读；没有借助未上传素材的指代。最终提示词只需要新产品图和文字即可执行。

用户当前明确要求可覆盖本 Skill 的默认设置；单次修改不自动更新已保存母版。只有产品本身不清楚、不同款无法确定目标、不是裤装且动作无法局部适配，或缺少确实不可回避的结构信息时，才集中询问必要问题。

## 固定母版

- 约12.04秒、9:16、正常速度真人实拍观感，9镜8次硬切。仅整数秒入口使用12秒，只缩短最后定格约0.04秒。
- 同一28岁成年男性：浅橄榄肤色、灰绿眼、较宽椭圆脸与略圆下颌、浓平眉、偏宽鼻梁及圆鼻尖、薄唇、均匀短胡茬、深棕后梳微波纹发；黑色合身长袖扣衬衫塞腰、米色宽檐牛仔帽、深棕尖头低跟靴。产品图不定义人物和搭配。
- 同一停车场、短草地、暮色冷软光；8.375秒硬切暖光黑夜，11.375秒硬切回暮色。保留白线、草带、右后灯杆、夜景草岛及长影方向。
- 后侧细节指示 → 已蹲低后起身 → 侧走 → 正面站姿 → 右手按帽低头 → 硬切左手持帽遮脸再戴回微笑 → 后侧轻触 → 夜景连续走近低头侧身指裤 → 回开场细节。
