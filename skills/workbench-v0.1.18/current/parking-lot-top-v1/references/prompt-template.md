# 停车场上衣：默认换款提示词

这是基于截图原稿的可复用版本。常规请求按此顺序和节奏输出；衣服外观由新商品图决定。所有平铺改用用户明确指定的沥青路面。用户只要“按停车场上衣写提示词”时，不自动附加文案配音或真人讲话。

下方正文可作为生成基础。对新品进行最少必要适配：删除不适用于新品的触摸部位，改用图片里确实存在的边缘；按可见服装重量调整小幅风动；没有拉链时不提拉链。不要把这些编辑说明或任何占位符输出给视频模型。

## 参数修改

- 要求16.5秒：最后段写14.0—16.5秒；前八段和构图不变。
- 明确要求30秒：保留9镜头顺序，按时长合理延展动作停留，不把旧17秒切点留在30秒提示词中。
- 明确要求9:16：改为9:16并重新保护商品与人物安全区，不能同时保留3:4要求。
- 新商品图有领口拉链：可加入“领口拉链头固定在领口，外部项链吊坠位于更下方，二者保持清楚距离”；没有则不加入。
- 新商品图无袖口：第七镜头改为轻托其真实下摆或可见边缘，不生成袖子。
- 新商品图材质厚薄不清：只描述小幅位移、重力回落和稳定主体，不写具体纤维、弹性或保暖性能。
- 用户要求配音字幕：用独立女声画外配音，逐句同文字幕；17秒文案保持简短，并允许跨相邻镜头连续，不强迫1.1秒镜头装入长句。人物依旧静默。
- 用户要求实际生成平铺图：依本次商品图生成沥青路面图，使用图像工具；该操作由当前制作请求触发，不是写提示词的默认步骤。
