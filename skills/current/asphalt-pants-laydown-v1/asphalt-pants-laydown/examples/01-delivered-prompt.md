# 上一轮交付的中文提示词

建议参数：约 11 秒，9:16 竖屏。本示例记录上一轮文本交付，不证明用户实际生成时未作调整；以后使用本 Skill 时，新商品图决定裤子外观。

生成一条真人穿搭展示视频，主角是已上传产品图中的裤子。采用沥青地面躺拍造型，由拍摄者从高位斜俯拍，沿整套穿搭上下游走，重点展示裤子的整体轮廓、腿部线条以及裤脚与鞋面的关系。整条视频采用一个连续长镜头，人物基本保持躺姿，画面变化主要来自摄影者的手持移动。

【产品参考】
已上传的产品图仅作为裤子的外观参考。裤子的颜色、面料可见纹理、腰头、门襟、拼接线走向、裤腿宽度与裤脚形状均以图片为准，整条视频保持同一条裤子。根据躺姿自然改变褶皱和垂落方向，保留产品原有结构。图片中的站姿、上衣、鞋子和白色背景不进入成片。

【人物与搭配】
一位身形修长、比例自然的成年穿搭模特，穿着参考图中的裤子，仰躺在一块无人通行、干燥的深灰色沥青地面上，正在配合穿搭拍摄。身体沿画面对角线延伸，肩部朝画面上方，双脚朝画面下方。一条腿较自然地伸展，另一条腿轻微向外弯曲，双腿彼此分开，裤腿轮廓清楚。

搭配白色长袖内搭、深灰色短款牛仔外套、棕色皮带与小面积银色金属扣，脚穿黑色尖头皮鞋。外套自然展开搭在胸肩处，白色内搭与腰线适度露出。模特一只手臂自然放在身侧地面，另一只手轻扶靠近脸部的外套边缘，使脸部保持遮挡。头颈、躯干、手臂与双腿连接自然完整。这是有人穿着服装的躺拍展示，不是空衣服摆拍。

人物保持放松，只出现轻微呼吸、指尖松动和幅度很小的脚踝调整。裤子随身体受力产生少量真实褶皱变化，保持有重量的落地状态。

【场景与光线】
背景始终是同一片深灰色粗颗粒沥青，可见少量浅色石粒。地面占据服装周围的留白，没有车辆、行人和额外道具。

采用柔和、明亮的户外散射光，整体中性略冷，曝光稳定。裤面朝上的位置略亮，褶皱内侧与贴地位置形成柔软阴影，让裤子的颜色与深灰色地面清楚区分。保留参考图中的裤子本色，不把它调成白色、黑色或橙黄色。

画面有真实布纹、拼接线和沥青颗粒，不使用强烈金色滤镜、夸张光晕或突然变化的明暗。空气平静，衣物的微小变化来自身体动作，不刻意制造大风吹动。

【连续运镜与展示节奏】
以下是同一个长镜头中的三个连续阶段，不是三个切换镜头。

0—4秒：
画面从靠近人物的沥青局部开始。摄影者轻快地斜向扫入人物腰腿区域，起步有短暂、自然的手持运动模糊，裤子入画后迅速变得清晰。镜头随后沿腰头、大腿、膝部向裤脚移动，速度逐渐减慢，视线顺着裤腿的拼接线向下。抵达裤脚后短暂停留，让观众看清裤脚覆在黑色鞋面上的堆叠，以及一伸一曲的双腿形成的宽松轮廓。模特仅轻轻调整脚踝，裤脚褶皱随之发生很小的变化，鞋与地面的接触关系稳定。

4—7秒：
承接裤脚停留，摄影者沿原有身体方向缓慢反向回扫，从裤脚经过膝部、大腿，回到腰头与皮带位置。裤腿两侧的轮廓和拼接线在连续移动中逐步显露。镜头接着带到白色内搭和深灰色外套下缘，展示上装与裤装之间的搭配比例。人物保持原有躺姿，扶住外套边缘的手指轻微放松，裤子、皮带与上衣之间的位置关系连贯。

7—11秒：
摄影者稍微抬高手持位置，让胸肩、腰线、两条裤腿和鞋子进入更完整的斜俯拍构图。外套边缘持续遮挡脸部，周围仍是同一片沥青地面。短暂呈现整套造型后，镜头顺着身体方向再次向下游走，将注意力重新交还给裤子。最后画面以腰部以下的裤装为主，两条裤腿及裤脚与鞋面的关系清楚可见，在轻微手持移动中自然结束。

【摄影与连续性】
采用手机主摄般的自然透视，近似35毫米等效视角，镜头始终位于人物上方斜俯拍。通过摄影者实际移动和轻微抬高手位改变构图，保留克制的手持微晃；裤型不因广角畸变被过度拉长。

整条视频保持同一个人物、同一条裤子、同一套搭配、同一片地面和同一种光线。人物不站起来、不翻身、不走路，不出现倒地过程。相机连续移动，不切镜、不叠化、不突然环绕、不把画面变成旋转商品展示。裤腿始终与两条腿对应，拼接线不游移，衣物不悬浮、不融化、不凭空变款。

【声音与文字】
本版生成无配音、无背景音乐、无字幕的纯画面素材。人物不说话、不对口型。画面不添加标语、价格、品牌标识或促销贴纸，便于后期单独搭配音乐或添加画外配音与字幕。
